# Mutual Fund Data Analysis Report

## 1. Project Overview
This project analyzes mutual fund performance data using Python, Pandas, NumPy, and Matplotlib.

## 2. Dataset Details
- Total rows: 40
- Total columns: 19
- Missing values: 0
- Duplicate rows: 0

## 3. Analysis Performed
- Loaded the mutual fund CSV dataset.
- Checked missing values and duplicate records.
- Calculated average 1-year, 3-year, and 5-year returns.
- Identified the top five funds by 3-year returns.
- Compared average returns across fund categories.
- Created a bar chart.

## 4. Results
- Average 1-year return: 14.38%
- Average 3-year return: 14.09%
- Average 5-year return: 14.52%
- Highest category average 3-year return: Small Cap, at 21.69%.

## 5. Output Files
- reports/category_returns.png
- reports/top_5_mutual_funds.csv

## 6. Conclusion
The analysis demonstrates how Python can be used to inspect, analyze, and visualize mutual fund performance data.
